# Digital Amnik CRM

Agency Operating System & Client Resource Management portal for **Digital Amnik**.

## 🌟 Key Features
- **Executive Admin Command Center**: Staff roster management, attendance selfies verification, client account tracking, deliverable delegation, and project timesheets.
- **Employee Studio Portal**: Shift check-in/out, live deliverable task timers, lunch tracking, and procedural ambient audio focus studio.
- **30-Day Attendance & Persistence**: Auto-recovery from Supabase, selfie verification, and 30-day attendance history tracking.
- **Shift & Timing Management**: Standard agency office shift (10:30 AM - 07:00 PM) with live HUD and late check-in protocols.
- **Role & Domain Architecture**: Multi-domain specialist support (Video Editing, Graphic Design, Social Media Management, Paid Ads, SEO, Content Writing, Web Development).
- **Security & Permissions**: Strict deliverable creation & delegation rights reserved for the Agency Owner (Amaan Khan) and Social Media Managers.
- **Supabase Cloud Backend**: Real-time cloud synchronization for employee rosters, timesheets, deliverables, and PDF calendars.

## 🚀 Running Locally
```bash
python -m http.server 3000
```
- **Employee Studio**: [http://localhost:3000/](http://localhost:3000/)
- **Admin Command Center**: [http://localhost:3000/admin.html](http://localhost:3000/admin.html)
